# 实验协议

## 1. 目的

验证"视觉对准 + 接触搜索"的线缆/连接器插入闭环在随机初始位姿下的成功率与失败模式。

## 2. 变量

| 变量 | 设置 |
|---|---|
| 插头初始 x/y | 标称值 ±20 mm 均匀随机 |
| 插头初始 z | ±5 mm |
| 插座 | 固定（示教位姿） |
| 光照/背景 | 固定（仿真） |
| 相机 | 固定俯视，640×480 |
| 试验次数 | 20 |

## 3. 指标

- `success`：尖端进入孔内且横向误差 <10 mm
- `grasp`：抬升后插头跟随
- `perception`：插头/面板标记均检测到
- `lateral_mm`：成功时尖端相对插座中心的 y-z 误差
- `max_force`：插入过程最大接触力
- `retries`：力超限后的回退/螺旋次数
- `failure`：`grasp_failed` / `insert_stuck` / `insert_timeout`

## 4. 结果（2026-11，seed=7）

| 指标 | 值 |
|---|---|
| 成功 | 18/20 = 90% |
| 抓取 | 20/20 |
| 感知 | 20/20 |
| 平均横向误差 | 6.5 mm |
| 最大横向误差 | 9.5 mm |
| 失败 | `insert_stuck` ×1、`insert_timeout` ×1 |

CSV：`media/trials.csv`

## 5. 复现

```bash
.venv/bin/python scripts/evaluate.py 20
```

## 6. 消融建议

- `use_taught_socket=False`：纯视觉插座估计
- 关闭横向闭环（只做一次对准）
- 关闭螺旋搜索
- 缩小孔间隙到 2 mm
- 增加相机噪声/光照扰动

## 7. 注意

- 仿真抓取是刚性 assist，成功率不代表真实摩擦夹持。
- 力上限未硬约束；峰值 ~57 N 的卡滞重试在真机上不允许。
- 插座 34 mm 方孔偏大，真实连接器需要更小间隙。
