# 线缆连接自主作业 · 项目规划（Franka / ROS2 版）

**参照**：`SY1777/TianY2.0_wireconnect`（第二届世界人形机器人运动会·灵巧手专项赛·线缆连接赛道）
**目标**：用 12 周做一个"桌面版"线缆连接全自主 demo，跑通感知—规划—抓取—插入—验证—恢复，再迁移到人形/灵巧手或实验室真机
**适合谁**：已有 ROS2 + Gazebo + MoveIt2 基础、做过 Franka 抓取 demo、想进机器人实验室或备战 2027 赛季的本科生

---

## 0. 结论先行

1. **不要复刻"人形 + 灵巧手"**。你现在的 Franka 仿真环境已经能跑抓取，最划算的路线是：**Franka + 平行夹爪 + 线缆插头**，把"插入"这件事做深；人形平台等有队/有设备再迁移。
2. **12 周目标**：仿真插入成功率 ≥ 80%，真机 ≥ 60%（如果有真机）；形成 **repo + 3 分钟视频 + 12 页报告**，直接作为进实验室/大创/竞赛的敲门砖。
3. **你的差异化不是调包，是机电一体化**：3D 打印夹具、相机支架、ESP32 急停/通断检测、线缆固定——这些是纯 CS 同学做不了的，也是 WireConnect 作者在 README 里抱怨"硬件问题吃掉时间"的地方。
4. **从 WireConnect 学到的核心**：仅靠单目相机 + 贴纸/YOLO 不够稳；"空间站对接"式插入（粗对准 → 接触 → 旋转/螺旋搜索 → 力反馈）比纯视觉可靠；比赛前一周才写完 95% 代码 = 高风险。

## 1. 参考项目拆解

### 1.1 WireConnect 做了什么

| 维度 | 内容 |
|---|---|
| 任务 | 天轶 2.0 Pro 人形机器人 + 灵巧手，线缆连接（插头抓取 → 对准 → 插入） |
| 技术栈 | ROS2 Humble · MoveIt2 · YOLO · OMPL |
| 代码量 | 作者自述"占 95% 以上代码量" |
| 硬件 | 仅靠相机识别贴纸/线缆，无额外传感器；机械/硬件问题多 |
| 周期 | 赛前一周完成主体 |
| 仓库 | `.vscode`、`completion`、`config`、`data/param`、`detect`、`src`、`frames_*.pdf`、`readme.md` |
| 提交信息 | "加大手的力、减少连接器臂步长"、"加入 2mg 监听手势遥控"、"线缆连接空间站对接打法，通过旋转控制" |

### 1.2 它做对了什么

- **任务闭环完整**：不是只做检测/只做规划，而是从相机到夹爪/灵巧手到插入的完整链路。
- **工程化意识**：config 与 param 分离、detect 独立、completion 任务脚本、测试工具和文档都自己写。
- **插入策略明确**："空间站对接"式——先粗对准，再靠旋转/微调/力反馈完成对接，而不是要求一次视觉定位到 0.1mm。
- **承认限制**：README 直说只靠相机识别贴纸/线缆、硬件问题多、时间紧。这种"可复现的诚实"反而让人信。

### 1.3 它没解决/没时间做的事（你的机会）

1. **视觉鲁棒性**：从公开描述看，主要依赖相机识别贴纸/线缆，深度、手眼标定、失败恢复没有体现；换光照/换位姿容易崩。
2. **仿真保真度**：接触、摩擦、线缆柔性、相机噪声、延迟都没对齐真机。
3. **真机时间**：赛前一周才收尾，真机调试被压缩。
4. **评价体系**：缺少"20 次 × 多条件"的成功率、时间、力峰值、失败分类。
5. **可复现性**：没有一键启动、没有测试、没有数据/标定说明。

## 2. 项目定义

### 2.1 一句话

> 机器人从桌面抓取线缆插头，移动到面板插座前，完成对准与插入，并用"力 + 视觉 + 电气通断"三重验证确认连接成功；失败时能自动退出、重试。

### 2.2 任务分级（不要一上来做最难的）

| 级别 | 对象 | 难点 | 建议 |
|---|---|---|---|
| L1 | **USB-C** 插头/插座 | 对称、有倒角，容错高 | 第 1–3 周，先跑通闭环 |
| L2 | **RJ45** 网线 | 有方向键，需要旋转对齐 | 第 4–6 周，主力 demo |
| L3 | **圆形航空插头**（GX16/LEMO 类） | keyway + 螺纹/卡扣 + 柔性线缆 | 第 7–10 周，冲刺/竞赛 |

### 2.3 平台

- **仿真**：Franka Panda / FR3 + Franka Hand，Gazebo + MoveIt2（复用你现在的环境）
- **真机**：实验室 Franka（首选）；没有就借/租；再退一步用轻量臂（松灵 Piper、Aubo i5）
- **相机**：腕部 USB 相机（eye-in-hand）+ 桌面俯视相机（可选）
- **验证**：ESP32/STM32 做插头—插座通断检测，串口转 ROS2 话题 `/insertion_verified`

### 2.4 非目标（明确不做）

- 不做人形全身运动、不做多指灵巧手（除非你已有平台）
- 不做柔性线缆的完整动力学建模（先用短线段 + 夹具约束）
- 不追求"一次成功"，追求"可重复 + 可恢复"

### 2.5 复用你现在的 demo

你视频里的 Gazebo + Franka + ArUco 方块抓取，已经解决了 60% 的工程问题。直接改：

| 现在 | 改成 |
|---|---|
| `grasp_cycle.py` 抓方块放到盒子上 | `insertion_cycle.py`：抓插头 → 对准 → 插入 → 验证 |
| `cartesian_move.py` 一段直线 | 拆成 `approach / align / insert / retreat` 四段 |
| 方块上的 ArUco | 插头 + 插座上的 ArUco（先做真值，再换 YOLO） |
| MoveIt2 MotionPlanning 面板手动点 | 状态机自动调用，面板只用于调试 |
| 夹爪反馈 "non-success" | 加 ESP32 通断检测 + 力阈值，做三重验证 |

                │                           │
┌───────────────▼──────────────┐  ┌─────────▼─────────────────┐
│ 感知层                       │  │ 规划/控制层                │
│ aruco_detector.py            │  │ moveit_client.py           │
│ connector_detector.py (YOLO) │  │ cartesian_path.py          │
│ pose_estimator.py (PnP/深度) │  │ moveit_servo（视觉伺服）    │
│ hand_eye 标定                │  │ 力控/阻抗控制              │
└───────────────┬──────────────┘  └─────────┬─────────────────┘
                │                           │
        ┌───────▼───────────────────────────▼───────┐

        └────────────────────────────────────────────┘

### 3.1 ROS2 节点

| 节点 | 输入 | 输出 | 说明 |
|---|---|---|---|
| `aruco_detector` | 相机图像 | `/plug_pose_aruco` | 初期真值/标定用 |
| `connector_detector` | 相机图像 | `/plug_bbox`、`/port_bbox` | YOLOv8，后期替换 ArUco |
| `pose_estimator` | bbox + 深度/模型 | `/plug_pose`、`/port_pose` | PnP 或点云配准 |
| `moveit_client` | 目标位姿 | 轨迹 | OMPL / Pilz / Cartesian |
| `insert_controller` | 力/位姿 | 速度指令 | 螺旋搜索、力阈值、回退 |
| `state_machine` | 各节点状态 | `/task_state` | 任务编排、失败恢复 |
| `continuity_check` | 串口 | `/insertion_verified` | ESP32 通断/电阻 |

### 3.2 关键坐标系

`world → table → panel → socket → plug → tcp → camera`；所有位姿统一用 `tf2` 发布，禁止在代码里写死变换。

## 5. 任务分解与状态机

### 5.1 状态表

| 状态 | 进入条件 | 动作 | 成功条件 | 失败 → 恢复 |
|---|---|---|---|---|
| IDLE | 启动 | 回 home，等待 `/start` | 到位 | — |
| DETECT | 收到 start | 检测插头/插座，发布位姿 | 两个位姿置信度 > 阈值 | 重拍/换视角/人工示教 |
| APPROACH | 位姿有效 | MoveIt2 到插头预抓取位 | 到达 ±5mm | 重规划 |
| GRASP | 到达 | 闭合夹爪，读指距/电流 | 指距在插头厚度范围 | 重抓（±2mm 偏移） |
| LIFT | 夹住 | 抬升 5cm，看插头是否跟随 | 视觉/力确认跟随 | 放下重抓 |
| ALIGN | 抓起 | 移到插座前 5cm，轴线对齐 | 位姿误差 < 2mm/2° | 视觉伺服微调 |
| INSERT | 对齐 | 直线插入 + 力监控 + 螺旋搜索 | 力突降/到位/通断 | 回退 2cm，重对准 |
| VERIFY | 插入到位 | 通断检测 + 视觉 seating | 通断 + 图像确认 | 重插 |
| RELEASE | 验证通过 | 松爪，退开 | 插头留在插座 | — |
| HOME | 完成 | 回安全位 | — | — |

### 5.2 插入策略（核心）

1. **粗对准**：预插入点放在插座轴线正上方 5cm，姿态误差 < 3°。
2. **视觉伺服**：用腕部相机把插头尖端对齐到插座中心（图像误差 < 5px）。
3. **接触**：沿轴线低速下降，直到力 > 2N。
4. **螺旋搜索**：以 1–3mm 半径、0.2mm 步长做阿基米德螺旋，同时保持 2–5N 接触力。
5. **旋转对齐**（L2/L3）：绕轴线 ±15° 扫描，监测力矩/电流，找到 keyway。
6. **到位判定**：轴向力突降 + 位置到位 + 通断信号（三重）。
7. **失败回退**：卡住 → 退 2cm → 重新视觉对准 → 最多重试 3 次。

### 5.3 为什么"空间站对接"式有效

纯视觉要求一次定位到亚毫米，单目 USB 相机做不到；而"接触 + 搜索 + 力反馈"把精度要求从"视觉"转移到"机构/控制"，容错高一个数量级。WireConnect 的提交信息里"通过旋转控制"就是这个思路。

## 7. 感知与数据

### 7.1 标定

1. 相机内参：`camera_calibration` / OpenCV 棋盘格。
2. 手眼标定：eye-in-hand，ArUco 板，`easy_handeye` 或 OpenCV `calibrateHandEye`。
3. 插座/插头模型：游标卡尺 + CAD，记录关键尺寸（插入深度、倒角、keyway 角度）。
4. 验证：把 ArUco 贴在插头上，比较预测位姿与真值，误差 < 2mm/2° 才继续。

### 7.2 检测路线

| 阶段 | 方法 | 目的 |
|---|---|---|
| 第 1 阶段 | ArUco + PnP | 跑通闭环，拿真值 |
| 第 2 阶段 | YOLOv8n bbox + 深度 | 去掉 ArUco，接近真实 |
| 第 3 阶段 | 关键点/6D pose（可选） | 圆形插头 keyway 对齐 |

### 7.3 数据

- 合成：Blender/Gazebo 渲染 2000 张，随机光照、纹理、位姿、遮挡。
- 真实：200–500 张，手机/相机多角度；标注 bbox + 关键点。
- 增强：亮度、对比度、运动模糊、噪声、部分遮挡。
- 划分：train/val/test = 70/15/15；按"场景"划分，避免同场景泄漏。

### 7.4 指标

- 检测：mAP@0.5、关键点 PCK、位姿误差（mm/°）。
- 插入：成功率、平均时间、力峰值、恢复率。
- 系统：端到端延迟、CPU/GPU 占用。

## 9. 真机与安全

### 9.1 安全清单

- 硬件急停（切断使能），软件急停（ROS2 服务）
- 力上限 20N，速度缩放 10–20%
- 工作空间限制（MoveIt2 `workspace` 参数）
- 看门狗：主循环 > 100ms 未更新 → 停止
- 真机第一次只做"空走"（不接触），第二次低速接触，第三次完整

### 9.2 sim-to-real 清单

| 项 | 仿真 | 真机 | 对策 |
|---|---|---|---|
| 相机 | 理想针孔 | 畸变/噪声/曝光 | 标定 + 真实图像微调 |
| 摩擦 | 参数可调 | 未知 | 系统辨识/域随机化 |
| 延迟 | 低 | 10–50ms | 降速 + 预测 |
| 线缆 | 刚体 | 柔性 | 短段 + 夹具 + 力控 |
| 夹爪 | 理想 | 指距/电流噪声 | 通断/力反馈兜底 |

## 13. 风险与备选

| 风险 | 概率 | 影响 | 对策 |
|---|---|---|---|
| 没有真机 | 高 | 无法验证 sim-to-real | 先做 M1–M3；借实验室/租云平台；用轻量臂替代 |
